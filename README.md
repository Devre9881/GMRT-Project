# GMRT-Project

This project focuses on enhancing the data correlation efficiency of the Giant Metrewave Radio Telescope (GMRT) system. I worked on implementing corrections for two GMRT antennas to ensure accurate synchronization and signal integrity. The project involved processing high-speed astronomical data on the GMRT supercomputer, Paramrudra, which utilizes GPU acceleration for large-scale computation.

To optimize performance, I developed a custom logic for chunk-based data processing instead of traditional full-size data handling. This modification significantly reduced memory and computational overhead, leading to a 35% reduction in system load on the Paramrudra setup.

This work improves real-time data correlation throughput and enhances the overall efficiency of the GMRT signal processing pipeline, contributing to faster and more reliable astronomical observations.
